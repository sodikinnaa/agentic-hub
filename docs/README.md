## 🛠️ Ringkasan Fitur Utama Modul
- **Catalog & Pricing Engine**: Pengelolaan produk, SKU, harga promo, dan checkout direct link.
- **AI Tool Calling / Function Calling**: Mencegah halusinasi harga/stok AI CS dengan dynamic database query (`search_products`, `get_product_detail`, `list_promo_products`, `check_stock`).
- **Multi-Role Scopes**: Otoritas berjenjang dari CS Support (Level 1) hingga Super Copilot (Level 4).
- **Multi-Tenant Gateway Integration**: Mendukung Fonnte & Meta Cloud API Webhook Router.
